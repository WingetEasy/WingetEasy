# Privacy Policy — WingetEasy

**Last updated:** October 27, 2026

WingetEasy is an open-source, local-first utility designed to help users manage Windows Package Manager (`winget`) updates with full transparency and zero telemetry.

---

## 1. Zero Data Collection
- **No Personal Information:** WingetEasy does not collect, store, transmit, or share any personal identifiable information (PII).
- **No Telemetry / Analytics:** The application does not send analytics, telemetry, crash reports, or usage data to external servers or third-party services.
- **Local Storage Only:** All update histories, backups, snapshots, profiles, and user preferences are stored strictly on the local machine in a local SQLite database (`%LocalAppData%\WingetEasy\`).

---

## 2. Network Usage
WingetEasy connects to the internet strictly for:
1. Executing official `winget.exe` CLI queries against Microsoft's official package catalogs (`winget` and `msstore`).
2. Checking for new WingetEasy releases via GitHub Releases through the Velopack updater (if enabled).
